# M238 Dashboard Mobile

Aplikasi mobile Expo/React Native untuk M238 Digimap PIM 2.

Fitur utama:
- Daily Sales live
- Daily Summary bulanan
- Staff Performance
- Reporting & Checklist Store
- Data mengambil backend yang sama dengan https://m238-dashboard.vercel.app
- Siap dijalankan di Expo Go dan dibuild dengan EAS

Jalankan:

```bash
npm install
npx expo start
```

Build:

```bash
npx eas build --platform ios
npx eas build --platform android
```
